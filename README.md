# Focus Guard

Focus Guard - браузерное расширение для снижения количества отвлекающего
контента во время работы или учебы.

Расширение работает на YouTube, Rutube, VK и VK Видео. Оно позволяет скрывать
рекомендации, комментарии, короткие видео, ленту ВКонтакте и отдельные пункты
меню VK.

## Возможности

- скрытие рекомендаций рядом с видео;
- скрытие Shorts и клипов;
- скрытие комментариев;
- скрытие ленты ВКонтакте;
- выборочное скрытие разделов меню VK;
- таймер Pomodoro с настраиваемым временем фокуса и отдыха;
- автоматическое включение блокировок во время фокус-сессии;
- уведомления о завершении фокуса и отдыха;
- подсчет времени и количества завершенных сессий;
- синхронизация настроек средствами браузера.

## Установка и запуск

Для работы проекта не требуется установка зависимостей или запуск локального
сервера. Расширение загружается непосредственно в браузер.

### Google Chrome

1. Скачайте или клонируйте репозиторий:

   ```bash
   git clone https://github.com/ekaterinaadamova/FocusGuard.git
   ```

2. Откройте в Chrome страницу:

   ```text
   chrome://extensions/
   ```

3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `FocusGuard`, содержащую файл `manifest.json`.
6. Закрепите Focus Guard на панели браузера для быстрого доступа.

Аналогичным способом расширение можно установить в другие браузеры на базе
Chromium, например Microsoft Edge. В Edge используется страница
`edge://extensions/`.

## Использование

1. Откройте YouTube, Rutube, VK или VK Видео.
2. Нажмите на значок Focus Guard на панели браузера.
3. Включите нужные блокировки.
4. При необходимости нажмите **Применить сейчас**, чтобы сразу обновить
   открытую страницу.

Для запуска фокус-сессии задайте продолжительность работы и отдыха, затем
нажмите **Старт**. Во время фокуса расширение включает все блокировки. После
завершения сессии блокировки отключаются и начинается отдых.

## Обновление локальной версии

После изменения файлов проекта откройте `chrome://extensions/` и нажмите кнопку
обновления на карточке Focus Guard. Затем перезагрузите открытые страницы
поддерживаемых сайтов.

## Структура проекта

- `manifest.json` - настройки и разрешения расширения;
- `popup.html` - интерфейс всплывающего окна;
- `popup.js` - настройки, таймер и статистика;
- `content.js` - поиск и скрытие отвлекающих элементов на страницах;
- `background.js` - фоновые таймеры и уведомления;
- `styles.css` - стили элементов, добавляемых расширением;
- `icons/` - иконки расширения.

## Разрешения

Расширение использует хранилище браузера для настроек и статистики, уведомления
для таймера, вкладки для применения изменений и доступ к поддерживаемым сайтам
для скрытия выбранных элементов интерфейса.

## Технологии

- HTML и CSS;
- Chrome Extensions API;
